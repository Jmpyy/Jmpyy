### 👤 Sobre mí

Soy un desarrollador de software enfocado en la arquitectura y creación de aplicaciones web escalables. Actualmente curso mis estudios en la **Universidad Provincial de Ezeiza (UPE)**. Mi pasión es resolver problemas complejos de negocio mediante código limpio, integrando tecnologías eficientes desde el diseño de bases de datos relacionales hasta interfaces de usuario reactivas.

*   🔭 **Actualidad**: Construyendo **Plaxia** (mi propio SaaS médico) y desarrollando plataformas avanzadas de logística y monitoreo de flotas.
*   🌱 **Aprendizaje**: Profundizando en **Arquitectura de Software**, **Seguridad Backend** y lenguajes de bajo nivel como **C**.
*   💡 **Filosofía**: Código limpio, mantenible y aplicación de buenas prácticas (SOLID, Clean Architecture).
